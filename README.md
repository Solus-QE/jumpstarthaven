# jumpstarthaven

https://mrvalk.itch.io/cool-game

This is a game that was intentionally made to be difficult. The control keybinds randomly switch every time you click them between the ones that are available (a, s, d, space, z, down, right, left). Moreoever, the character is extremely large, which adds the the difficulty of the game as the hitbox is only within its center. You need to traverse the to the end of the obstacles and jump off the win the game.
